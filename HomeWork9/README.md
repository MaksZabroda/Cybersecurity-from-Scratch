# Домашнє завдання до уроків 9–10: діагностика мережі

## Опис

`net_diag.sh` — це Bash-скрипт для швидкої перевірки мережі на комп'ютері.
Він нічого не змінює в системі, а лише збирає інформацію та показує результат
у зрозумілому вигляді.

Скрипт працює на:

- Linux;
- macOS;
- WSL (Linux усередині Windows).

Після запуску скрипт сам визначає платформу та вибирає відповідні системні
команди.

## Що перевіряє скрипт

### 1. Мережеві інтерфейси та IP-адреси

Скрипт показує активні мережеві інтерфейси, наприклад Wi-Fi або Ethernet,
та призначені їм IPv4 і IPv6-адреси.

Для цього використовуються:

- `ip` або `ifconfig` у Linux та WSL;
- `ifconfig` у macOS.

### 2. Шлюз за замовчуванням

Шлюз — це пристрій, через який комп'ютер виходить із локальної мережі в
інтернет. Зазвичай це домашній або офісний роутер.

Скрипт знаходить адресу шлюзу та інтерфейс, через який проходить основний
мережевий маршрут.

### 3. DNS-сервери

DNS перетворює доменні імена, наприклад `example.com`, на IP-адреси. Скрипт
показує DNS-сервери, які зараз використовує система.

У macOS інформація береться через `scutil`, а в Linux і WSL — через
`resolvectl` або файл `/etc/resolv.conf`.

### 4. Доступ до інтернету

Спочатку скрипт робить короткий HTTPS-запит до `example.com` за допомогою
`curl`. Він отримує лише заголовки відповіді та чекає максимум п'ять секунд.

Якщо HTTPS-перевірка не вдалася, скрипт відправляє один `ping` на адресу
Cloudflare `1.1.1.1`. Це допомагає перевірити мережеве з'єднання навіть тоді,
коли є проблема з DNS або HTTPS.

### 5. Локальні порти

Скрипт показує порти, які прослуховуються на комп'ютері. Це означає, що певна
програма або служба очікує мережеві підключення через ці порти.

Залежно від системи використовуються `ss`, `lsof` або `netstat`.

## Як запустити

Перейти до папки зі скриптом:

```bash
cd HomeWork9
```

Додати право на виконання:

```bash
chmod +x net_diag.sh
```

Запустити скрипт:

```bash
./net_diag.sh
```

Для звичайного запуску `sudo` не потрібен.

## Як читати результат

Кожна перевірка має один зі статусів:

- `[ OK ]` — інформацію отримано або перевірка пройшла успішно;
- `[FAIL]` — перевірка не вдалася або необхідна команда відсутня.

Наприкінці скрипт показує загальну кількість перевірок, кількість успішних
результатів і кількість помилок.

Кольори можна вимкнути командою:

```bash
NO_COLOR=1 ./net_diag.sh
```

## Код завершення

Скрипт повертає:

- `0`, якщо всі обов'язкові перевірки отримали статус `OK`;
- `1`, якщо хоча б одна перевірка отримала статус `FAIL`.

Переглянути код завершення після запуску можна так:

```bash
echo $?
```

## Безпечне виконання

На початку скрипта використовується суворий режим Bash:

```bash
set -euo pipefail
```

Він допомагає помічати помилки команд, використання неоголошених змінних та
помилки всередині конвеєрів. Команди, які можуть не спрацювати під час
діагностики, обробляються окремо, тому скрипт виконує всі перевірки та показує
підсумок.
