# HomeWork 11 — звіт про ризики ПЗ

Домашня робота демонструє навчальний конвеєр керування вразливостями:
пошук CVE через NVD, перевірку фактичної експлуатації через CISA KEV,
отримання прогнозної оцінки EPSS та формування пріоритетів P1–P4.

## Автоматична інвентаризація та вибір програм

Під час кожного запуску скрипт визначає операційну систему, прибирає дублікати
та зберігає повний список програм у `inventory.json`. На macOS він читає
`Info.plist` із `/Applications` і `~/Applications`, на Windows — системні та
користувацькі гілки реєстру для 32- і 64-бітних програм, а на Linux використовує
перший доступний пакетний менеджер `dpkg`, `rpm` або `pacman`. Зовнішні команди
Linux запускаються без `shell=True`. Потім із програм, для яких визначено
версію, випадково вибираються п'ять позицій. Під час останнього перевіреного
запуску на macOS знайдено 107 програм і вибрано:

| Програма | Встановлена версія |
|---|---:|
| Tunnelblick | 8.0 (build 6300) |
| Xerox Print and Scan Experience | 4.0.0 |
| Spotify | 1.2.72.438 |
| OneDrive | 26.145.0728 |
| IBM Aspera Connect | 3.11.2 |

Наступний запуск сформує нову випадкову вибірку та перезапише звіт.

## Запуск

```bash
cd Cybersecurity-from-Scratch/HomeWork11
source .venv/bin/activate
pip install -r requirements.txt
python homework11.py
```

У Windows оточення активується командою `.venv\Scripts\activate`, після чого
скрипт так само запускається через `python homework11.py`.

Без `NVD_API_KEY` скрипт автоматично робить паузу 6 секунд між запитами до
NVD. За наявності ключа його можна записати у локальний файл `.env`, який
виключено з Git:

```dotenv
NVD_API_KEY=ваш_справжній_ключ
```

За замовчуванням результат зберігається у `risk_report.csv`. Інше ім'я можна
вказати через `python homework11.py --out інший_звіт.csv`.

## Результат запуску

Остання перевірка повернула 12 CVE: по 3 для Tunnelblick, Spotify, OneDrive та
IBM Aspera Connect. Для Xerox Print and Scan Experience NVD не повернув
збігів. Усі 12 CVE відсутні в CISA KEV, мають EPSS нижче 0.1 і за правилами
завдання отримали пріоритет `P4`.

## Аналіз хибних збігів

У поточному звіті отримано дванадцять знахідок, але їх не можна автоматично вважати підтвердженими вразливостями цього комп'ютера. Три старі CVE для Tunnelblick датовані 2012 роком, тому сама згадка назви не доводить їх застосовність до встановленої версії 8.0. CVE-2018-1167 стосується Spotify 1.0.69.336, а CVE-2017-17750 насправді описує пристрої Bose SoundTouch, тому обидва збіги не відповідають поточному клієнту Spotify 1.2.72.438. CVE-2018-0592 і CVE-2018-0593 згадують OneDrive без придатного діапазону версій, тоді як CVE-2018-14901 взагалі описує драйвер Marvell WiFi у ядрі Linux. CVE-2020-4545 стосується IBM Aspera Connect 3.9.9, але дві знахідки 2023 року для Aspera можуть потребувати окремої перевірки за рекомендацією IBM, оскільки встановлена версія 3.11.2 є старою. Відсутність результатів для Xerox Print and Scan Experience також не доводить безпечність програми, бо продукт може бути записаний у NVD під іншою назвою. Головна причина неточностей — пошук за ключовим словом без перевірки CPE, операційної системи та діапазону вразливих версій, тому всі результати потребують ручної валідації.

## Файли

- `homework11.py` — основний скрипт із детальними коментарями українською.
- `requirements.txt` — зафіксовані залежності Python.
- `inventory.json` — автоматично створений повний інвентар (не додається в Git).
- `risk_report.csv` — фактичний результат запиту до NVD, KEV та EPSS.
